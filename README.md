# Puissance 4

Jeu local pour deux personnes, réalisé en HTML, CSS et JavaScript natifs.

## Jouer

Ouvre `index.html` dans un navigateur récent. À tour de rôle, chaque personne choisit une colonne pour déposer un jeton. Le premier alignement de quatre jetons à l’horizontale, à la verticale ou en diagonale remporte la partie. Une grille pleine sans alignement donne un match nul.

Les commandes fonctionnent à la souris, au tactile et au clavier : les flèches gauche/droite déplacent le focus entre les colonnes, puis Entrée ou Espace joue le jeton.
